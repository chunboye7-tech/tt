# XIUJIN Shopify theme

`XIUJIN-theme.zip` is the Shopify theme upload package prepared for the XIUJIN office and gaming chair wholesale store.

## Download and upload

1. Open `XIUJIN-theme.zip` on GitHub and choose **Download raw file**.
2. In Shopify Admin, go to **Online Store → Themes → Import theme → Upload zip file**.
3. Upload the ZIP and preview it before publishing.

The ZIP should be uploaded as-is. Do not unzip it before uploading to Shopify.
